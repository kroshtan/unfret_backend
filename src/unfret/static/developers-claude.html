Use Unfret in Claude

Unfret checks whether an online store or product page looks legit, sells generic junk, or shows signs of a scam, and shows the evidence behind it. With the Unfret connector, ask Claude about a link before you buy and it runs the check for you. No account and no e-mail: signing in makes an Unfret pass for the connection.

# the Unfret connector
{{base_url}}/mcp

Add the connector

In Claude (claude.ai, Claude Desktop and the mobile apps): open Connectors, choose Add, then Add custom connector, and enter {{base_url}}/mcp. On a Team or Enterprise plan an Owner adds connectors for the organization. In a chat, turn Unfret on from + > Connectors.

In Claude Code:

claude mcp add --transport http unfret {{base_url}}/mcp

Then run /mcp in Claude Code to sign in. Other MCP clients that support OAuth sign-in work the same way; clients that send a header instead can use a pass directly, as the developer page shows.

Signing in

Claude can connect, list Unfret's tools and look up prices before you sign in. The first check is what asks you to: Claude shows a Connect button, and Unfret's sign-in page opens.

  1. Continue. Unfret makes a pass for this connection (a few seconds of proof of work in your browser, instead of an account). A new pass is a developer pass: it comes with up to {{free_checks}} free deep checks while today's free checks last. Or open I already have an Unfret pass and paste one you have (it starts with ufk_), to use the checks on it.
  2. Keep the pass and its backup code if you want them: the page shows them once, folded away. You need them to add checks later or to use the same pass in the browser extension or the phone app. Unfret stores only one-way hashes, so it can't show them again.
  3. Go back to Claude. Claude retries the check that asked you to sign in.

Signing in involves no payment. The connection's token works only for the connector, lasts an hour, and Claude renews it on its own.

The tools

  • check_store_quick, Quick check of a store (free): rules on the page itself (discount tricks, dropshipping apps, fake timers, missing legal information, …). It changes nothing, so Claude can run it without asking. It also says whether a deep check is worth it.
  • check_store_deep, Deep check of a store (uses a check): everything in the quick check plus an AI read of the listing, its reviews, photos, price history and domain age. It uses one check from your pass (free checks first), so Claude asks you before running it unless you've allowed it.
  • get_checks_left, Checks left on the pass: how many deep checks your pass has left, and whether free deep checks are paused for today.
  • get_pricing, Unfret prices: what checks cost and the packs a pass can buy.

The connector can't spend money: it has no payment tool, and it only ever uses checks already on the pass.

What it costs

Quick checks are free. A deep check uses one prepaid check from the pass: its free checks first, then bought ones. Checks are bought for a pass on the checkout page, by card or other methods, in packs; they don't expire. When the pass has none left, the deep check says so, charges nothing, and the quick check still works.

Things to ask

  1. "Is this store legit? https://…" Claude runs the free quick check and tells you what it found, and whether a deep check would add anything.
  2. "Run a deep check on this product page before I order: https://…" Claude runs the full check (after asking you) and explains the verdict and the evidence behind it.
  3. "I'm choosing between these two shops for the same item, which looks safer? https://… and https://…" Claude checks both and compares what each check found.
  4. "How many Unfret checks do I have left?" Claude looks up the pass.
  5. "What does an Unfret deep check cost?" Claude looks up the current prices.

Reading a result

Every check returns a verdict (Looks fine, Worth a look, Think twice or Serious concerns), a suggested action (allow, warn or block), a risk score and the flags it found, each with its evidence. The policy setting (strict, balanced or lenient) decides how soon the action warns or blocks. Flags are evidence to weigh, not proof that a shop is a scam: read what each one says, and see how accurate the checks are.

Troubleshooting

  • "Couldn't read the page" (page_unreadable): some sites, marketplaces such as Amazon in particular, refuse visits from servers. Nothing was charged. The browser extension checks the page you have open, or a client that has the page's HTML can send it as page_content.
  • No checks left (no_checks_left): nothing was charged. The quick check still works; buy checks for the pass, or get_checks_left says where.
  • Free deep checks paused: everyone's free deep checks share one daily budget. Once it's used, they're back after 00:00 UTC; bought checks and quick checks work meanwhile.
  • Claude asks you to connect again: the sign-in ended, because it was disconnected, unused for 30 days, or the pass was replaced with its backup code. Choose Connect and sign in again (paste your pass to keep its checks).
  • "Retry shortly" (unavailable): too many checks in a short time. Nothing was charged; wait the time it names and ask again.
  • The connector won't connect at all: remove it and add {{base_url}}/mcp again. If it still fails, write to us with the time it happened and, if Claude shows one, the reference ID of the error.

Disconnecting and your data

Disconnect any time in Claude's connector settings. Replacing the pass with its backup code also ends every sign-in made with it. For a connection, Unfret keeps one-way hashes of the sign-in's tokens, tied to the pass, with when they expire; nothing about who you are. The connector sends Unfret only the link to check (and the page, if a client sends it), never your conversation. What Unfret keeps about checks and pages, and for how long, is in the privacy policy; the terms apply to the connector as to the rest of Unfret.

Support

Questions, problems and security reports: hello@unfret.net. If it's about your pass, include the pass's ID (on My checks), never the pass or its backup code. A shop owner who thinks a result about their site is wrong can ask for a review. The connector's code is open source, in the Unfret repository.
