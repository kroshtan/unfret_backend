Get Unfret for your browser

Unfret is in the Chrome Web Store and on Firefox Add-ons, and keeps itself up to date. Pick the store for your browser.

Add to Chrome Add to Firefox

Chrome Web Store: Chrome, Brave, Edge, Vivaldi, Opera and other Chromium browsers. Firefox Add-ons: Firefox.

After installing

  1. Pin it. Click the puzzle piece in your browser's toolbar and pin Unfret, so it's one click away.
  2. Get some checks. Buy a pack by card or crypto, or use an intro code if someone shared one with you.
  3. Click Unfret on a product page. It reads that page, only when you click, and answers in plain words.

On a phone, or a computer where you can't add extensions? Check a link on the web instead; a few shops block those checks, the extension isn't affected. The code is open source.
