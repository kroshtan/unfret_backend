Install the Unfret extension

Unfret is in the Chrome Web Store. It works in Chrome, Brave, Edge, Vivaldi, Opera and other Chromium browsers, and updates itself from there.

Get Unfret from the Chrome Web Store

On a phone, or a computer where you can't install extensions? Check a link on the web instead (some shops block those checks; the extension isn't affected).

The code is open source. Firefox isn't supported yet.
