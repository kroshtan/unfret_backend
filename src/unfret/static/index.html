For developers and AI agents

Shopping agents can ask Unfret before they pay: one HTTP call per check over x402, paid in USDC or SOL with no account, or the MCP server that does it for them. The answer is an action (allow, warn or block) and the evidence behind it. Open source, MIT licensed.

Developer guide API reference

# Any MCP client: the agent pays from its own wallet
uvx unfret-mcp

# Or call the API yourself
POST https://unfret.net/v1/check
