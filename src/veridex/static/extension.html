Install the Unfret extension

This page installs Unfret straight from this server, without an app store: a signed package that updates itself from here. The code is open and releases are reproducible, so anyone can check that a download matches the source.

Brave, Chromium or Chrome on Linux

Chromium browsers install extensions from outside the Chrome Web Store through a browser policy. Run the command for your browser, restart it, and Unfret appears in the toolbar. It then updates itself from this server.

Check brave://policy (or chrome://policy) after restarting. A policy-installed extension can't be removed from the extensions page: delete the unfret.json file you created and restart to uninstall.

Windows and macOS

On a personal Windows or macOS computer, Chromium browsers only accept policy-installed extensions from outside the Chrome Web Store when the device is managed (Active Directory or device management). Otherwise: download the zip above, unzip it, open brave://extensions, turn on Developer mode, click Load unpacked and pick the folder. That works, but the browser shows a developer-mode notice and there are no automatic updates.

Verify a download

From the extension's source repository: make install && make verify-release CRX=unfret-<version>.crx checks the signature, the extension ID and that the contents are byte-identical to your own build.
